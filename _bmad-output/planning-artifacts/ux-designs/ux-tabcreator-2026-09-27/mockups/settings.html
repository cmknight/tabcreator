TabCreator — Settings screen (key screen)

1:1 static mock of #/settings, plus the Keyboard shortcuts dialog (?) and the Unsupported browser screen. Settings changes save automatically (no Save button). Sections reuse the Analysis settings panel look from tab.html.

1 · Light theme — defaults, theme System, storage protected

Defaults for new takes use the same controls as the Tab screen's Analysis settings panel (US-4.6 defaults: 0.50, 40 ms, 24) without a Re-analyse button. Theme is a segmented control with System pressed. Storage status pairs its colour with an icon; the engine version is in the numeric face.

3 · Alternate states (light)

Same frame width and content as frame 1 unless noted.

(a) Keyboard shortcuts dialog

Opened with ? or the Settings button. Lists every shortcut from Interaction Primitives, grouped by where it works. Focus is trapped while open; Close (or Esc) returns focus to the element that opened it. Only dialogs cast a shadow.
